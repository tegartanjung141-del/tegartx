## Optimization Tips untuk WebGL

### Memory Optimization
1. Gunakan Asset Bundles untuk large assets
2. Compress textures (ASTC atau ETC2)
3. Reduce mesh complexity
4. Use occlusion culling

### Performance Optimization
1. Batch static objects
2. Use GPU instancing
3. Minimize draw calls
4. Reduce overdraw
5. Use LOD for complex models

### Build Size Optimization
1. Enable managed code stripping
2. Use incremental garbage collector
3. Remove unused modules
4. Compress audio files

## Troubleshooting

### Common Issues

**Issue**: WebGL context lost
- **Solution**: Reduce memory usage, lower quality settings

**Issue**: Slow performance
- **Solution**: Enable profiling, optimize shaders, reduce draw calls

**Issue**: Build too large
- **Solution**: Enable code stripping, compress assets, use asset bundles

**Issue**: Browser compatibility issues
- **Solution**: Test on multiple browsers, use polyfills if needed
